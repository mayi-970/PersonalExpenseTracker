# PersonalExpenseTracker
This is a complete full stack project designed to track day-to-day (or) any stipulated time frame income and expenses of an individual.

# Income
* you can add and edit your income in different domains like Freelancing, Salary, Bussiness, etc...
* you can visualize your income in different time frames through the graphs using recharts library.

# Expense
* you can add and edit your Expense in different domains like Rent, Food, Shopping, Bills, etc...
* you can visualize your Expense in different time frames through the graphs as well.
